# Name and brand use

RankMiso's code is MIT-licensed. Fork it, change it, ship it. This page does not change the MIT license or any rights it already grants, including rights to files in this repository.

The RankMiso name, the fox mark, and the Miso ecosystem name identify the official builds. No registered trademark is claimed. This is a request to help people know what they are installing.

## Official distributions

- The RankMiso listing on the Chrome Web Store
- The RankMiso listing on Firefox Add-ons (add-on ID `rankmiso@rankmiso.extension`)
- Source and builds from [github.com/EdeesonOpina/rankmiso](https://github.com/EdeesonOpina/rankmiso)

## If you publish a fork

- Use a different name and icon in the store listing and the manifest.
- Do not present the fork as official, endorsed, or made by the Miso ecosystem.
- Saying "based on RankMiso" is fine, and appreciated.

`apps/extension/src/config/brand.config.ts` holds the name and tagline, and [docs/branding/asset-replacement.md](docs/branding/asset-replacement.md) explains how to replace the icon.
