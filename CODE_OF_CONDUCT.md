# Code of conduct

People working on RankMiso are expected to:

- Discuss the work, not attack the person.
- Accept correction about privacy, security, and accuracy.
- Give newcomers enough context to continue.
- Refuse changes that collect user data quietly or present guessed metrics as measurements.

Maintainers may close comments or contributions that harass people, include exploits against unwilling targets, or misrepresent what the tool can know. Report conduct problems the same way as security reports until a public contact exists.
