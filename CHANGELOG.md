## 0.1.0

First development slice. This is not a public store release.

- Local on-page analysis for the rendered page: metadata, headings, content counts, links, images, JSON-LD syntax, social tags, a limited accessibility sample, and browser-observed performance values when the browser exposes them.
- Weighted checklist score that excludes checks which could not be evaluated.
- Popup, full report, options page, and a side panel entry.
- JSON, CSV, and HTML export, plus browser print.
- Page highlighting that can be cleared.
- No accounts, telemetry, or required network services.

Checks that need response headers, robots.txt, sitemaps, reciprocal hreflang, broken-link requests, rich-result rules, or search-engine index data are reported as not measured.
