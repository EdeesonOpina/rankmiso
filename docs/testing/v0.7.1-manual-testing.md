# RankMiso v0.7.1 — manual testing checklist

One checklist for the whole v0.7.1 build. Fill the Chrome and Firefox columns with **Pass**, **Fail**, **Blocked**, or **N/A**, and add a note for anything that is not Pass. Nothing here has been marked by anyone yet; automated results are listed separately in section 0.

## Setup

1. **Builds** (from `~/Downloads/BUILDS/rankmiso-v0.7.1-final-test/`, all manifest version 0.7.1):
   - Chrome or Edge: `chrome://extensions` (or `edge://extensions`) → Developer mode → **Load unpacked** → `chrome/` (or `edge/`).
   - Firefox: `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → `firefox/manifest.json`. A temporary add-on is removed on restart, so it cannot test restart persistence.
   - Use a fresh browser profile so earlier permissions do not carry over.
2. **Fixture site**: `node MANUAL-FIXTURES/m11-fixture-site.mjs`, then open <http://127.0.0.1:8471/>. Every page is made up; the index links to all of them.
3. For real-site checks, use sites you own or are allowed to test.

## Known limits to keep in mind

- Firefox: HTML comparison fetch is Chromium-only; everything else uses the same code but has not been run in Firefox by automation.
- Restart persistence in Firefox needs a signed install.
- Crawler readings use RankMiso's own requests; real crawlers may be treated differently by firewalls or bot management.
- Visibility is what you record; RankMiso never queries AI services.
