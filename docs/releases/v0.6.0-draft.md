# RankMiso v0.6.0 — Draft

**Status:** Release candidate notes, not published. The owner authorizes store submission and the GitHub release. Until then, Chrome Web Store and Firefox Add-ons serve v0.5.1.

## Overview

RankMiso v0.6.0 turns Site Explorer from a page list into a site-wide SEO view. After a crawl you choose, it shows what the analyzed pages have in common: which findings repeat, which titles and descriptions are duplicated, and how pages link to each other. Everything still runs in your browser, on the pages the crawl fetched.

## What's new

- **Site Overview:** pages analyzed out of the 100-page limit, issue types, duplicate metadata groups, and analyzed pages grouped by their worst finding (errors, warnings, neither). Metadata and page-structure totals sit below. There is no site-wide score.
- **Issues:** findings grouped by rule across pages, with category, severity, a suggested fix, and the affected pages with their evidence. Search, filter by category or severity, and sort.
- **Pages:** every crawled address with its status and findings; open one to see its details.
- **Internal Links:** source and target pages, the target's state (analyzed, failed, skipped, not crawled), redirect target, anchor text and link attributes, and the number of analyzed pages linking in. Pages with zero or one incoming source are listed as a bounded observation, never as orphans.
- **Duplicate metadata:** repeated titles and meta descriptions (ignoring case and extra spaces) with the pages that share them.
- **Redirect-aware counts:** several crawled addresses that end at the same final page are counted once.
- **Site Analysis CSV:** a new typed export with summary, page, issue, duplicate and link rows.

## Improvements

- Faster site aggregation: 11.88 ms median for 100 pages and 20,000 detailed links in the local benchmark (Node 22.23.3, Linux x86_64, 5 runs), down from over 700 ms in the first Site Explorer 2.0 build.
- More accurate analyzed-page counts when addresses redirect to the same page.
- A crawl stopped by its two-minute limit now says "time limit reached".
- Duplicate detection no longer reports one redirected page as its own duplicate.
- Exports stay backward-compatible (see below).

## Compatibility

- **Chrome and Firefox:** same Site Explorer features in both. Firefox still excludes standalone sitemap discovery, PageSpeed Insights and the optional technical probes, as in v0.5.1.
- **Saved sessions:** the last crawl saved by v0.5.1 still opens. Its pages have no per-page finding data, so issue grouping and link details are incomplete for that session, and those pages are not counted as "without errors or warnings". Run a new crawl for full results.
- **Page CSV:** unchanged, 12 columns.
- **JSON:** schema version 1, unchanged required fields, with an added `siteAnalysis` object.
- **MCP companion and plugins:** unchanged and compatible. Site Explorer data is not shared through the companion; shared page audits keep the same format. No companion or plugin update is needed.

## Known limitations

- Results describe the bounded crawl (100 pages, depth 3, 120 seconds, 400 discovered addresses), not the whole website.
- In Chrome, a crawled address that redirects is recorded as a failed request ("Confirmed failed request" in Links). For safety the crawler does not let the browser follow redirects, and the browser does not reveal where a manual redirect points. This has been the case since v0.4.0. Redirect-aware counting therefore applies only where the redirect target is visible.
- Saved sessions keep at most 50 internal targets and 10 link details per page, so link observations from a reloaded session are marked truncated.
- Real-browser memory use and crawl timing have not been formally measured. The owner smoke-tested Site Explorer 2.0 in Chrome and Firefox; the full manual checklist has not been recorded scenario by scenario.

## Upgrading

Chrome and Firefox update the extension automatically. Nothing to reinstall, and no new permission prompt. To get full results for a site crawled with v0.5.1, run the crawl again.

## Security and privacy

- No new permissions or host permissions. Required permissions stay `storage`, `activeTab`, `scripting` (plus `sidePanel` in Chrome). HTTP/HTTPS access stays optional.
- No new network requests, endpoints, dependencies, telemetry or accounts. Firefox `data_collection_permissions.required` stays `["none"]`.
- The latest crawl is still stored only on this device, under the same storage key and size limit. It now also keeps short finding references and link details for the analyzed pages.
- No privacy-policy change is needed: the policy already covers a user-started, same-origin crawl whose latest session is stored locally.

## Store notes

**Chrome Web Store / Firefox Add-ons ("What's new")**

RankMiso 0.6.0 adds Site Explorer 2.0: after a crawl you start, see site-wide findings, duplicate titles and descriptions, and internal links across the pages it analyzed, and export a new Site Analysis CSV. No new permissions; everything stays in your browser.

**Permission change:** none. Manifests differ from v0.5.1 only by version.
