# RankMiso v0.6.0 — Draft

**Status:** Unreleased release-note draft. Site Explorer 2.0 is under final review; this is not a published release or store submission.

## What's new

- **Site-wide SEO overview:** Review supported findings and crawl coverage across the pages RankMiso analyzed.
- **Duplicate metadata detection:** Find repeated page titles and meta descriptions, with links to affected pages.
- **Internal link insights:** Explore observed same-origin relationships and bounded incoming-link counts.
- **Central issue explorer:** Search, filter, and sort supported findings, then open the affected page result.
- **Expanded exports:** Keep the existing page CSV format and download site-wide analysis as a separate CSV; JSON includes derived site analysis.

Site Explorer remains an explicit, local, same-origin crawl with the existing page and request limits. Results describe the bounded crawl and do not claim complete website coverage or duplicate page content.
