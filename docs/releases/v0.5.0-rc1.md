# RankMiso v0.5.0 Release Candidate 1

**Status:** unpublished candidate. Public version remains v0.4.0 until an owner-approved release.

## Release notes

RankMiso v0.5.0 adds an optional local MCP companion for sharing a specific SEO audit with Codex or Claude Code. The extension asks before saving an audit; the companion stores it in private per-user local storage. Five read-only tools let a configured MCP client list and retrieve shared audits, findings, comparisons, and crawl exports. The AI page includes connection status, Shared Audits management, and a built-in beginner guide.

The extension display name is **RankMiso — Free, Open-Source SEO Analyzer**; its short name remains **RankMiso**. The tagline remains **Every page. Every detail.** Chrome's production extension ID and Firefox's existing add-on ID must remain unchanged.

## Installation and distribution

See [Using RankMiso with AI Coding Assistants](../mcp/USER-GUIDE.md) and [MCP Companion installation](../mcp/INSTALL.md). The documented archive commands are `rankmiso-setup install`, `rankmiso-setup configure codex`, and `rankmiso-setup configure claude` (Windows uses `rankmiso-setup.exe`). Official download URLs are intentionally omitted until approved artifacts are published.

Archives use SHA-256 sidecars. Windows binaries require Authenticode signing for trusted direct distribution and may otherwise trigger SmartScreen. macOS executables require Developer ID signing with Hardened Runtime and Apple notarization; the current tar.gz format cannot be stapled, so the final signed distribution container still needs an owner-approved decision. Linux uses checksummed archives and does not require Windows/macOS-style signing.

Upgrade replaces companion executables without migrating or deleting snapshots. Uninstall removes companion binaries and browser registrations while preserving audit data and client configuration. The installer is per-user and installs no daemon.

## Privacy and remaining release work

Review [the v0.5.0 privacy proposal](v0.5.0-privacy-proposal.md) before publishing a privacy-policy update or submitting store packages. Chrome and Firefox store disclosures must match the package. Firefox RC declares optional `browsingActivity` and `websiteContent` consent for audit data; verify the live consent flow in Firefox before release. AI providers may process content retrieved from the local MCP server.

Release blockers: production Chrome-ID browser end-to-end test; Firefox live Native Messaging and sharing/retrieval/removal test; Windows and macOS browser end-to-end tests; browser permission lifecycle verification; approved public privacy policy; Windows signing; macOS signing/notarization and final container; approved public companion downloads; owner approval to publish v0.5.0.
