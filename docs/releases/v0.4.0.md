# RankMiso v0.4.0 release candidate

**Status:** Candidate prepared for review; not submitted or published. The published version remains v0.3.0.

## Full release notes

### RankMiso v0.4.0

**New and improved**

- Choose Automatic Website Checks with optional broad HTTP/HTTPS website access, or keep Individual Website Access for per-site control.
- Refresh now takes a fresh page snapshot and reruns local SEO analysis without reloading the website.
- The sidebar follows the active tab in its own browser window and protects against stale results during navigation.
- Firefox now supports user-started Site Explorer crawling with the shared crawler, permission checks, robots.txt handling, crawl limits, cancellation, and partial-result reporting.
- Improve crawl cancellation, History comparison accuracy, link highlighting and cleanup, and sidebar-to-full-report navigation.
- Replace the Score History empty-state illustration with RankMiso’s head-only fox icon.

Website access remains optional. Automatic Checks requests broad HTTP/HTTPS access only after the user chooses it. Individual Website Access remains available. Crawling and other network checks require their own user action. Firefox does not include standalone remote sitemap discovery, PageSpeed Insights, or the Chromium-only optional technical probes.

## Chrome Web Store short notes

RankMiso 0.4.0 adds optional Automatic Website Checks, per-site access, fresh Smart Refresh, and improved sidebar synchronization. Firefox Site Explorer parity and more reliable History, highlighting, and crawl cancellation are included. Website access remains optional; crawls start only when you choose Start.

## Firefox Add-ons short notes

RankMiso 0.4.0 adds optional Automatic Website Checks, per-site access, fresh Smart Refresh, and improved sidebar synchronization. Firefox now supports user-started, same-origin Site Explorer crawling with robots.txt handling, limits, and Stop. Standalone sitemap discovery, PageSpeed Insights, and other Chromium-only remote checks remain unavailable in Firefox.

## Permission summary

- Required permissions remain `storage`, `activeTab`, and `scripting`; Chrome additionally uses the existing `sidePanel` permission. Firefox retains optional `tabs` and the existing Gecko identity.
- HTTP/HTTPS host access is optional. It is not granted at install. Automatic Checks asks for broad HTTP/HTTPS access; Individual Website Access requests the selected host pattern. Host permission patterns do not restrict ports.
- Firefox's `data_collection_permissions.required` remains `["none"]`.
- No telemetry, account, remote audit service, or backend is added.

Before submitting this extension, update the Network Requests disclosure to identify both Chrome and Firefox for the user-started, selected-origin crawl, preserve the Firefox-only exclusions, describe permission approval and denial accurately, and retain the limits, robots, cancellation, local storage, and credential-free request wording. The exact policy correction should state:

RankMiso requests browser access to that website if needed. The crawl requests pages directly from that website, observes robots.txt, and stops at 100 pages, depth 3, 2 concurrent requests, or 120 seconds. Requests omit browser credentials. ### Proposed Privacy Policy Version 7 replacement wording

Preserve Version 6 in the policy history. When v0.4.0 is actually available, replace the v0.3-only/upcoming-feature statements and Chrome-only Site Explorer disclosure with a reviewed version of the following:

> **Website access:** RankMiso can request optional access to HTTP and HTTPS websites. Automatic Checks uses the browser's broad HTTP/HTTPS grant to inspect only the active page in the browser window where the RankMiso sidebar is open, while that sidebar is open and Automatic Checks is enabled. Individual Website Access requests a selected site's host access. Both require your approval; you can deny or revoke access in browser controls. Revocation prevents later authorized inspections and requests; a request already sent may finish.
>
> **Site Explorer (Chrome and Firefox):** A crawl starts only when you choose Start crawl. RankMiso requests pages directly from the selected origin (same scheme, hostname, and port), reads robots.txt and sitemap data as part of that crawl, uses no browser cookies or authorization credentials, and sends no referrer. It applies page, depth, concurrency, request-time, response-size, redirect, discovery, and total-duration limits. You can stop the crawl; closing its report stops further work. Results are processed in your browser and the latest session is stored on this device; a crawl may be partial and does not resume automatically. Firefox does not provide standalone sitemap discovery, PageSpeed Insights, or the Chromium-only optional technical checks.
>
> **Network-address limitation:** RankMiso checks URL origins and blocks recognized literal local/private address destinations and redirects outside the selected origin. Browser extension networking does not provide RankMiso a portable way to pin a hostname to the IP address used by the connection. RankMiso therefore cannot guarantee that a public hostname will not resolve or change to a local/private address during a crawl. Only crawl websites you trust. Do not treat same-origin validation as a guarantee against DNS rebinding.
>
> **Local storage:** Site Explorer stores its latest crawl results on this device. Automatic page checks do not save History. Saved audit comparisons remain stored only when you explicitly save them. Clear saved settings removes the stored crawl session; browser permission revocation does not itself delete saved History or crawl results.

This wording does not make the unresolved network-address risk acceptable by disclosure alone. Security acceptance remains blocked until the runtime boundary is demonstrated or crawling is safely constrained.

## Permission purpose copy for store forms

**Optional HTTP/HTTPS website access:** Used only after the user approves it. It enables Automatic Checks to inspect the active page while the RankMiso sidebar is open, and enables Individual Website Access for selected sites. Site Explorer makes direct requests only after the user explicitly starts a crawl. Automatic Checks does not crawl or save History. Users can revoke access in browser settings. Core SEO analysis is local; there is no telemetry or remote audit backend.

Do not describe Automatic Checks as active-tab-only browser permission: the browser grant is broad HTTP/HTTPS access even though RankMiso limits its automatic inspection lifecycle to the active page while the sidebar is open.

## Release gates still open

- Native Firefox permission denial/revocation, request-log checks, robots, redirect safety, limits, and cancellation have not all been verified. The product owner confirmed basic Firefox Site Explorer runtime only.
- Installed Chrome regression remains unverified; Playwright Chromium passing is not installed Chrome evidence.
- DNS rebinding cannot be ruled out by the current hostname-based private-address checks. Treat this as a security review blocker until a supported safe boundary is demonstrated or the behavior is explicitly restricted.
- Confirm the public policy's updated wording has been deployed before store submission.
- No release tag, commit, push, or store submission is authorized in this preparation milestone.
