# RankMiso v0.7.1 — draft release notes (not released)

Status: integrated on `feature/v0.7.1-m11-integration`, awaiting owner manual acceptance. Not pushed, not tagged, not submitted.

## What is new

- **JavaScript SEO diagnostics** (Technical → HTML comparison): seven signals compared between the initial HTML and the rendered page, with evidence and next steps. Firefox compares a chosen HTML file only.
- **Discoverability** (Site intelligence):
  - Crawler access: robots.txt readings for 18 documented crawlers and tokens across Google, Bing, DuckDuckGo, Brave, Apple, Yandex, Baidu, ChatGPT, Gemini, Copilot, Claude, Perplexity, and DuckDuckGo AI answers; indexing directives; Microsoft AI Training and Grounding preferences (in effect from 2027-02-01).
  - Content readiness: structure, clarity, attribution, structured data consistency, and accessibility checks grouped for AI-assisted discovery. No score.
  - Visibility: a local log of AI answers the user recorded; RankMiso never queries AI services.
- **Canonical and hreflang relationships** in Site Explorer, judged only between pages the crawl analyzed.
- **Redirect trace** (Technical), hop by hop, with optional redirect details.
- **Structured data** checks for required properties (as Google lists them), value types, URLs, conflicts, references, and article attribution, across JSON-LD, Microdata, and RDFa.

## Permissions

New optional permission: `webRequest`, requested only when the user chooses **Allow redirect details**. No new required permission, no new host permission, no data collection change.

## Compatibility

Page score unchanged by the new findings (they have weight 0 or sit in the zero-weight structured data category). Audit, snapshot, saved-audit, crawl-history, and export formats are unchanged; crawl pages gain optional `hreflang` fields. Existing `RULE_HREFLANG_INVALID` and `RULE_SCHEMA_RICH_RESULTS` now follow Google's documentation, so some pages change result.

## Known limits

Firefox runtime, signed-install persistence, and the permission prompts for site access and redirect details have not been exercised by automation. Crawler readings are not crawl, index, ranking, or citation results.
