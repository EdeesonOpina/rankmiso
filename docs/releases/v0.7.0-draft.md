# RankMiso v0.7.0 — Draft

**Status:** Version-alignment correction proposed on `fix/v0.7.0-version-alignment`. This branch generates 0.7.0; current `staging` still generates 0.6.0. Not published. Release qualification remains blocked until the correction completes the branch workflow and staging is rebuilt.

## Overview

RankMiso v0.7.0 adds Site Explorer 3.0. After a crawl you start, you can save it on this device and compare it with a later crawl of the same site. The comparison shows new, resolved, and unchanged findings, metadata changes, and internal-link changes. It does not invent a fix when a page was not crawled again or when stored evidence was shortened. Analysis still runs in the browser. There is no account, backend, or telemetry.

## What's new

- **Save for comparison.** The open crawl can be kept for that site. Up to five snapshots per site, each within 350 KB, inside a 1.75 MB history budget. Saving is explicit. Delete removes one snapshot.
- **Compare crawls.** Choose a baseline and a later crawl, including the crawl that is open. Coverage, issue changes, and a reliability summary are separate from page changes, link changes, and duplicate-metadata changes.
- **Stable issue identity.** A finding is the final page plus the rule. Shortened evidence cannot become a new or resolved issue. Changed evidence on the same finding stays unchanged.
- **Partial crawls.** A page that was not analyzed both times stays not comparable. It is not reported as fixed.
- **Link lists.** Comparison snapshots keep the internal URLs the crawl collected, stored relative to the site, including query strings. A list is incomplete only when URLs were actually cut. Ordinary pages are not marked unable to compare.
- **Exports.** Comparison CSV has 12 columns. Comparison JSON uses schema version 1 and kind `rankmiso.siteComparison`. The existing page CSV, Site Analysis CSV, and Site Explorer JSON are unchanged.
- **Selection.** Changing either crawl, replacing the open crawl, or deleting the selected snapshot hides the previous result until you compare again.
- **Full-page report.** The footer keeps “Local analysis · No account · No telemetry” and **Refresh analysis**. **Open sidebar** is no longer in that footer. The sidebar and the popup still open the other surface.
- **Compare presentation.** The full-page compare view shows a dark summary, coverage of pages analyzed in both crawls, new / resolved / unchanged / not-comparable counts, issue activity, and internal-link counts. Those figures come from the comparison you run. The reference layout’s sample crawl is not stored.
- **Crawl status.** A crawl that finishes because it hit a limit is labeled **Finished at limit**. A crawl you stop is **Stopped**. A finished crawl that stayed inside its limits is **Complete**.

## Compatibility

- **Chrome and Firefox:** the same comparison features. Firefox 158.0.1 completed a local crawl, same-crawl comparison, a real title and heading change, link add and remove, CSV and JSON download, and reopening the report in the same session. A restart with a permanently installed unsigned add-on was not available on release Firefox.
- **Saved crawls from v0.6.0:** they still open. Snapshots saved before this storage change keep their original truncation. Missing links are not invented.
- **Page CSV:** 12 columns, unchanged.
- **Site Analysis CSV:** 22 columns, unchanged.
- **Site Explorer JSON:** schema version 1, unchanged.
- **MCP:** comparison history is not shared with the companion. No companion update is required.

## Known limitations

- Counts describe the bounded crawl, not the whole website. Fetched and listed counts include every record. Comparison counts each successful final URL once, so failures and redirect aliases are not extra compared pages.
- A snapshot that cannot fit in 350 KB keeps a shorter link list and marks those pages not comparable. Those missing links are not reported as removals.
- Release Firefox removes a temporary add-on when the browser quits. Restart persistence of comparison history was checked by reopening the report in the same session, not by quitting Firefox and relaunching a signed package.
- The package version in this candidate is 0.7.0. It remains unpublished.

## Security and privacy

- No new permissions. Required permissions stay `storage`, `activeTab`, and `scripting`, plus `sidePanel` in Chrome. HTTP and HTTPS access stays optional and is requested when a crawl starts.
- No telemetry, account, or hosted analysis. Crawl history stays in `localStorage` on this device.
- Stored page text is rendered as text. CSV formula characters are prefixed.
