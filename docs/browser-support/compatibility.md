# Browser compatibility

| Browser               | Build                        | Status                                                                                                                                                                                                                                           |
| --------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Chrome                | `wxt build`                  | v0.5.1 is published. It includes optional user-approved HTTP/HTTPS access, Site Explorer, and optional local AI sharing. Sharing through the v0.5.1 companion is verified in Google Chrome 156 on Linux x86_64. Native permission and installed-browser checks remain partial. |
| Edge                  | `wxt build -b edge`          | Same Chromium MV3 path. Sideload only; not on the Edge store.                                                                                                                                                                                         |
| Brave, Opera, Vivaldi | Load the Chrome package      | Expected to work where Manifest V3 and `sidePanel` match Chrome. Not installed here.                                                                                                                                                             |
| Firefox               | `wxt build -b firefox --mv3` | v0.5.1 is published. It includes optional HTTP/HTTPS website access, user-started Site Explorer crawling, and optional local AI sharing. Native Messaging audit sharing remains unverified in Firefox; the available Snap launcher could not run because this environment lacks required AppArmor confinement support. Standalone sitemap discovery, PageSpeed and optional technical probes remain unavailable; `data_collection_permissions.required` is `none`. Basic Site Explorer behavior has product-owner runtime confirmation; security scenarios remain open. |
| Safari macOS          | Not built                    | Needs Apple's converter, signing, and distribution. A successful future build command would not mean store support.                                                                                                                              |
| Safari iOS            | Not targeted                 | No feasible packaging in this version.                                                                                                                                                                                                           |

APIs used: `storage`, `tabs`, `scripting.executeScript`, `sidePanel` or `sidebarAction` when present, optional host requests in both development builds, and the page performance timeline. `webRequest` is not used. A requestable permission is not an installed grant.

If neither sidebar API exists, the sidebar button is hidden. The dashboard remains available. Playwright currently automates the built Chromium popup smoke path; Firefox, Edge, and live-page behaviors remain manual checks.
