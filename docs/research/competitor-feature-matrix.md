## Feasibility notes

Paid or private data is the hard boundary. Field Core Web Vitals, Ahrefs metrics, and SEOquake keyword difficulty need somebody else's dataset. This extension can link to an official validator or, later, call a free API after a click. It cannot calculate those numbers locally.

Browser APIs also differ. Chrome exposes `responseStatus` on navigation timing more readily than every other browser. Firefox sidebar and Chromium side panel are different manifest keys. WXT emits both when the side panel entry exists. Safari packaging is a separate Apple process.
