# Metadata

The metadata view shows the rendered title, meta description, robots, googlebot, bingbot, canonical, language, charset, and viewport. The snippet preview has desktop and mobile widths. The caption says search engines may rewrite the title and description.

Pixel width is an estimate of 7.5px per ASCII character and 14px per other character. It is labeled as an estimate.

Title and description length warnings use editorial ranges of 15–60 and 50–160 characters. The check text says these are not confirmed ranking thresholds.

`noindex` or `none` is a warning. The text says this is not proof that a search engine has dropped the page. Index status itself is an unavailable check.
