# Technical SEO

When navigation timing exposes a status, HTTP 4xx and 5xx are errors. A missing or zero status is unavailable, not a pass. Redirect count comes from the same API. Individual hops, their status codes, and response headers are unavailable.

Meta refresh is a warning. HTTPS is checked from the page URL. robots.txt and XML sitemaps are not fetched. The index-status check states that this tool cannot know whether a search engine has indexed the URL.

Client-side redirects are not fully detected. The history marker only tells the UI that the document changed.
