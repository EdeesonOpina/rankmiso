# Structured data intelligence (M11.4, unreleased)

Where: report → Schema (checks listed under the markup; evidence in Issues). Content readiness reuses the same checks by id.

Engine: `seo-rules::sd_entities`, called from the existing structured data checks. It reads every entity in JSON-LD (any depth, `@graph` included), Microdata, and limited RDFa into one list, so the same checks cover all three. Bounded to 300 entities. The StructuredData category has weight 0 in scoring, so the page score is unchanged; the count of measured checks grows.

## Checks

| Id                       | What it checks                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RULE_SCHEMA_RICH_RESULTS | Properties Google lists as required (Search Central, read 2026-11-25): BreadcrumbList `itemListElement`, ListItem `position`, `name`, and `item` except the last; Product `name` and one of `review`, `aggregateRating`, `offers`; LocalBusiness and 19 common subtypes `name` and `address`. Article and Organization: noted as having no required properties. FAQPage: noted that Google no longer shows FAQ rich results (2026). Missing → Warning. Complete → Info, never Pass, so it does not read as rich-result approval. Other types are shown but not checked. |
| RULE_SD_VALUE_TYPES      | ISO 8601 dates (`datePublished`, `dateModified`, `dateCreated`, `uploadDate`, `priceValidUntil`, `startDate`, `endDate`, `validFrom`, `validThrough`), numeric `price`, `lowPrice`, `highPrice`, rating values and counts, whole-number ListItem `position`                                                                                                                                                                                                                                                                                                             |
| RULE_SD_URL_VALUES       | `url`, `logo`, `image`, `sameAs`, `item`, `mainEntityOfPage`, `contentUrl`, `thumbnailUrl`: empty, spaces, `www.` without a scheme, or a non-web scheme. Relative paths are allowed.                                                                                                                                                                                                                                                                                                                                                                                    |
| RULE_SD_CONFLICTS        | the same `@id` with different `name`, `url`, `logo`, `telephone`, or `email`; the same type, name, and URL declared more than once without `@id`                                                                                                                                                                                                                                                                                                                                                                                                                        |
| RULE_SD_REFERENCES       | same-page `@id` references (`#org`) that no entity declares (Info)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| RULE_SD_ATTRIBUTION      | Article, NewsArticle, BlogPosting author or publisher without a name, directly or through a resolved `@id` (Info; Google recommends `author.name`)                                                                                                                                                                                                                                                                                                                                                                                                                      |

## Changed behaviour

v0.7.0's local checklist treated Article `headline`, `image`, `datePublished`, `author`, Product `image`, Organization and WebSite `name`/`url`, and FAQPage `mainEntity` as required. Google documents none of those as required, so the list now follows Google's pages. Microdata and RDFa entities are now checked too.

## Not done

No remote schema resolution, no full Schema.org vocabulary, no rich-result eligibility claims. Visible-page consistency (headline vs H1, url vs canonical, date contradictions) stays in Content readiness (`READY_SD_*`, `READY_DATES`), which now leaves JSON-LD date formats to `RULE_SD_VALUE_TYPES`.
