# Links

Links are classified as internal, external, anchor, mailto, tel, javascript, or other. Internal means the same host, ignoring a leading `www`.

Empty accessible names are warnings. `javascript:` links are notes. HTTP links on an HTTPS page are warnings. Nofollow, sponsored, and UGC are recorded and can be highlighted.

Broken-link checks stay off until **Check this site**. A link is not called healthy because it was not requested. Each press requests 20 public http(s) URLs, and the report shows the total still waiting.

CSV export includes classification, name, resolved URL, href, rel, and target. Cells that start with `=`, `+`, `-`, `@`, or a tab are prefixed so spreadsheets do not treat them as formulas.
